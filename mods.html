Stilton Mod Pack

All four of our Brick Rigs mods in one download, with one installer.

Download the mod pack

Zip file, about 9 MB · Windows · made for Brick Rigs 1.11.8

What is in it

  • Solid Debris – bricks that break off a build are solid in multiplayer, like in singleplayer. Key 9 switches it off or on.
  • Realistic Fire – fire burns longer, climbs, follows materials (wood burns, metal does not), weakens buildings until burned parts give way, and throws tall smoke. Key 8 switches it off or on; key 7 turns the extinguisher into a long-reach fire hose.
  • Medical – injuries heal far more slowly, and a badly hurt character blacks out until they recover or someone helps them.
  • Stilton CAD – the Stilton County CAD on screen: calls, units, your status and panic alerts. Press F4 for the mouse cursor, then click the panel’s buttons. Click Login once to sign in with Discord.

Who needs it

Solid Debris, Realistic Fire and Medical change the game for everyone only when the host runs them. Stilton CAD works for anyone who installs it.

Install

  1. Close Brick Rigs.
  2. Extract the whole zip to a folder (right-click the zip → Extract All).
  3. Double-click Install.bat. It finds your Brick Rigs folder and copies the mods in. Windows may ask whether to run it because it came from the internet; choose Run, or More info → Run anyway.
  4. Start the game. The first start takes about a minute longer than usual.

Remove

Run Uninstall.bat from the same folder, or follow the by-hand steps in the zip’s README.

Good to know

  • The mods run on UE4SS, an unofficial open-source script loader for Unreal Engine games, which is included in the zip. It is not made or supported by the Brick Rigs developers.
  • A game update can break them. If Brick Rigs will not start after an update, uninstall the pack.
  • Stilton CAD runs a small hidden helper while the game is open so it can reach the CAD. It closes itself when the game closes.
  • Bigger flames and smoke columns are only drawn on the host’s screen.
