Solid Debris

In multiplayer, bricks that break off a build normally let players walk straight through them. With this mod, loose bricks are solid again, like in singleplayer. When a chunk of a build breaks apart, the game’s collapse sound and dust cloud also play briefly at that spot.

Download Solid Debris

Zip file, about 9 MB · Windows · made for Brick Rigs 1.11.8

Who needs it

Whoever hosts the session. Players joining a host who runs it do not need it.

Install

  1. Close Brick Rigs.
  2. Extract the whole zip to a folder (right-click the zip → Extract All).
  3. Double-click Install.bat. It finds your Brick Rigs folder and copies the mod in. Windows may ask whether to run it because it came from the internet; choose Run, or More info → Run anyway.
  4. Start the game. The first start takes about a minute longer than usual.

Press 9 in game to switch the mod off or on. A chat line confirms the change.

Remove

Run Uninstall.bat from the same folder, or follow the by-hand steps in the zip’s README.

Good to know

  • The mod runs on UE4SS, an unofficial open-source script loader for Unreal Engine games, which is included in the zip. It is not made or supported by the Brick Rigs developers.
  • A game update can break it. If Brick Rigs will not start after an update, uninstall the mod.
  • On very large wrecks, freshly broken pieces can take up to about 2 seconds to become solid.
